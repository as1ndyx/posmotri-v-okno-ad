# Посмотри в окно

Вторая проектная работа Яндекс Практикума: приложение для просмотра видео из разных городов.

Репозиторий: https://github.com/as1ndyx/posmotri-v-okno-ad

## О проекте

На странице можно выбрать город и время суток, найти подходящие видео, переключаться между карточками и загрузить дополнительные результаты.

Вёрстка выполнена на Flexbox. Подключены локальные шрифты Fira Sans Condensed и Oswald. Оформлены состояния кнопок, карточек и полей формы, кастомные чекбоксы, прокрутка списка, прелоадеры и сообщения об ошибках. Длинные заголовки и описания карточек обрезаются внутри своих блоков.

HTML-разметка и логика приложения взяты из заготовки. Основная работа выполнена в `styles/style.css`.

[Макет в Figma](https://www.figma.com/design/ApJjZAA3pBv2tCZM9E2ul2/?node-id=1-214).

## Просмотр

Откройте `index.html` в браузере. Установка зависимостей и сборка не требуются. Для загрузки видео нужен доступ к внешнему серверу Яндекс Практикума.

Вёрстка рассчитана на ширину от 1200 px согласно заготовке. На широких экранах содержимое располагается по центру. Мобильная версия в этот этап не входит.

## Проверки

Исходный процесс `Tests` в `.github/workflows/tests.yml` запускает проверки Яндекс Практикума при отправке коммитов на GitHub. Для их выполнения репозиторий должен быть публичным.
